# Security policy

## Reporting a vulnerability

Report it privately on GitHub: the **Security** tab, then **Report a vulnerability**
([direct link](https://github.com/Jde-cpp/opc-hub/security/advisories/new)).  Please don't open a public issue.

Include the version (a release tag, or a commit), the part affected (the hub, the gateway, the OPC UA server, an
installer or the site), and the steps or input that trigger it.

## Supported versions

Only the [latest release](https://github.com/Jde-cpp/opc-hub/releases/latest) gets fixes.  A fix ships as a new
release; older releases are not patched.
